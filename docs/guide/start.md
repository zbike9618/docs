## 2. 建国（CountryWars）の基本
...

このサーバーの醍醐味である「建国」のアドオン機能です。

### 国の作り方
1. ゲーム内でチャットを開きます。
2. `/mc` と打ち込みます。
3. 国名と国家方針を選択します。
4. 送信するとあなたが国王の国が建国されます。

### 領土の保護
国を作ったら、自分の領土（チャンク）を買いましょう。
- 購入したいチャンクで、コマンド `/buyc` を実行します。
- 自国の領土内では、他国民によるブロック破壊やチェストの開閉が制限されます。(権限設定から変更可能)

::: warning ⚠️ 維持費に注意
所有しているチャンクには、毎日決まった時刻に「維持費」が国庫から自動で引き落とされます。
**国庫が維持費を支払えなくなると、国は自動的に解散してしまいます。** 領土を増やすときは、それに見合った収入源（職業や税収）も一緒に確保しましょう。
:::

## 3. 仲間を集める

一人で国を発展させるのは大変です。他のプレイヤーを国に招待しましょう。
- 国設定フォーム`/sc`を開き、国民タブから招待したいプレイヤーを招待します。
- 招待された側は`/mb`から参加できます。

## 4. 職業について

当サーバーでは、プレイヤーの活動を支援するための「職業」システムがあります。
職業に就くと、特定の行動（ブロック破壊、モンスター討伐など）に応じてお金が稼げるようになります。

### 職業の確認と就業
- 職業に関するメニューは、コマンド `/jobs` で開くことができます。
- メニュー内の職業を選択すると就業できます。

### 職業の制限
- 一度に就くことができる職業は **最大4つ** までです。
- 職業を変更したい場合は、現在就いている職業を辞めてから、新しい職業に就く必要があります。

### 職業の例
現在、以下の職業が用意されています。
- **鉱夫 (Miner):** 石や鉱石を採掘することで報酬が得られます。
- **狩人 (Hunter):** モンスターを討伐することで報酬が得られます。
- **林業 (Lumberjack):** 木を伐採することで報酬が得られます。
- **ネザー採掘 (Netherdigger):** ネザーのブロックを採掘することで報酬が得られます。
- **建築家 (Builder):** ブロックを設置・破壊することで報酬が得られます。

## 5. 経済を発展させる

### 銀行
コマンド `/bank` から、持っているコインアイテムを預けて残高（デジタルマネー）に変換したり、逆に残高を引き出して現物のコインに戻したりできます。
::: info 💡 ローンはありません
このサーバーの銀行に「借入（ローン）」の機能はありません。あくまで現金と残高を両替する場所です。
:::

### 税金
国の設定（`/sc`）から、消費税・所得税などの税率を設定できます。国民の収入や国内での買い物から自動的に税が徴収され、国庫に入ります。国庫は領土の維持費や戦争資金の元になるので、無理のない税率でしっかり運営しましょう。

## 6. 外交と戦争

### 外交関係
他の国とは「同盟」「友好」「敵対」の関係を結ぶことができます（国設定 `/sc` から操作）。
- **同盟**: お互いが申請・承認することで成立する関係です。
- **友好・敵対**: 一方的に設定できます。

### 戦争のはじめかた
`/war` コマンドから宣戦布告や講和の交渉ができます。
- 建国してから一定期間は「戦争保護期間」としてどの国からも攻撃されません。
- 借金を抱えている国・国民がいると宣戦布告はできません。
- 人数差が大きすぎる国同士は宣戦布告できないようにバランス調整されています。

宣戦布告が成立すると、`/invade` で敵国の領土に攻め込み、コアを破壊することで土地を奪えます。詳しいルールは[サーバールール](/guide/rules)の「侵略・戦争時の特例」も確認してください。

## 7. チャットを使い分ける
発言の届く範囲は、状況に応じて切り替えられます。
- `/wchat`: サーバー全体
- `/cchat`: 同じ国のメンバーだけ
- `/lchat`: 近くにいるプレイヤーだけ
- `/achat`: 自国と同盟国のメンバーだけ
