# 📜 サーバールール

建国鯖へようこそ！
すべてのプレイヤーが楽しく快適にプレイできるよう、以下のルールを定めています。参加前に必ず一読をお願いします。

## 🤝 紛争・揉め事について

::: info 🕊️ 基本は話し合い
- **まずは当事者同士で話し合いによる解決を試みてください。**
- 話し合いが不可能な場合や悪質な行為がある場合は、運営が仲裁・裁定を行います。
- 緊急で運営に助けを求める場合は、所定の方法で連絡してください。
- 意味もなく運営を呼んだ場合、重い処罰がされる場合があります。
- チャット履歴は全て記録されています。トラブル回避のため、合意等はチャット内で行うことを推奨します。
- **荒野について:** 荒野は誰の所有物でもないため、自由に活動（建築・破壊等）が可能です。
:::

## 🚫 禁止事項

以下の行為は、他プレイヤーの迷惑となるため厳禁です。

::: warning ⛔ 迷惑行為の禁止
- **プレイヤーキル (PK)、煽り行為**
- **他人の領地のブロック破壊**
- **プレイヤーへのいたずら・嫌がらせ**
- **窃盗行為:** 他人のアイテムを盗むこと
- **建築物へのいたずら:** 水や溶岩を流すなどの行為
- **モブへの干渉:** 他人の領土のモブを殺害したり移動させたりする行為
:::

::: tip ⚔️ 侵略・戦争時の特例
原則として他国への負の干渉は禁止ですが、**宣戦布告・侵略中**に限り以下の行為が許可されます。
- **許可されること:** 敵国プレイヤーのキル、コアの破壊
- **禁止されること:** ブロックの破壊行為
- **干渉権限:** 実行国・相手国・双方の同盟国のみが干渉可能です。（友好国は干渉できません）
:::

## ⚠️ 不正事項

サーバーの公平性を損なう行為は、即座に処罰（BAN等）の対象となります。

::: danger 🚨 厳禁な不正行為
- **バグ利用:** 悪質なバグ（アイテム増殖など）の使用
- **場所の制限:** エンドやネザーへの拠点・倉庫・装置・トラップの制作
- **嫌がらせ目的の領地取得:** 初期リス周辺チャンクを購入し、他プレイヤーを脱出不能にする行為
- **チート行為:** 不正MOD、外部ツール、不正クライアントの使用
- **有利になるリソースパック:** X-ray（透視）や暗視など、ゲームバランスを崩すテクスチャの使用
- **コアに関する不正:** コアの移動や、周囲をブロックで囲んで破壊不能にするなど、有利になる工作行為
:::
