# 【重要】サーバー接続障害の復旧とお詫び

平素より当サーバーをご利用いただき、誠にありがとうございます。

本日、一部のプレイヤー様においてサーバーに接続できない不具合が発生しておりましたが、現在は**正常に復旧**しております。

## 障害の内容
- **発生時刻**: 2026年5月6日（水） 午後
- **対象**: Nintendo Switch・Switch2版、および一部のプレイヤー
- **症状**: サーバーへの接続および参加ができない

## 原因
調査の結果、「フレンドコネクト（フレンド経由で参加する機能）」に関連するシステム更新の遅延が原因であることが判明いたしました。

## 現在の状況
現在はシステムのアップデートが完了し、**すべてのプラットフォームから正常に参加できる状態**となっております。

プレイヤーの皆様には多大なるご迷惑をおかけしましたことを、深くお詫び申し上げます。
今後とも当サーバーをよろしくお願いいたします。
